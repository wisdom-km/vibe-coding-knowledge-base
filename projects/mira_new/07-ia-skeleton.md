# 导演台的 IA 骨架（草案）

还没写进产品源码，也还没升成 `mira_new` 仓库里的正式地图。现在软件仍是好几个 ImGui 窗口并排。这份表是在说：如果要专业，屏幕该怎么组织。

模块之间的接缝（Command、快照）其实已经有了。缺的是「当前工作是什么」。剧本、资源、视口、分镜都像同等重要——功能齐了，主角太多。

下面按六条组织法，填成导演台自己的约定。借鉴的是分区方式，不是某软件的皮。

默认主舞台是 3D 视口。分镜审片是另一个工作区，不要长期和视口并排抢中间。  
选中同时只能有一个，类型可以是场景物体、相机或 Shot，检查器只认这一个。  
左边放「场景里有什么」和「还没进场景的资产」，中间看，右边改选中项，下面是镜头条，上面是菜单和当前模式的工具。  
工作区就三个：置景、掌机、审片。换工作区等于换工具条和哪些槽显示，槽的名字别改。  
每区一个主按钮。导出、官方下载这类进菜单或折起来。

如果以后认定导演台的本质是审片，只改「默认主舞台」那一行，走建议卡批准。没批准之前，按视口为主。

## 点哪里，算选中什么

| 你点的 | 选中 | 检查器改什么 |
|--------|------|----------------|
| 视口里的模型，或左边的节点 | 场景物体 | 名称、变换 |
| 相机列表，或视口上的相机控件 | 相机 | 预设、轨道 |
| 底条卡片，或剧本里的 Shot 行 | Shot | 关联哪台相机、标题；可以跳到视口 |

点分镜卡片就是选中 Shot。视口跟着跳到关联相机，那是跳转，不是第二套选择。不要剧本亮一套、视口亮另一套、检查器谁也不认。

## 槽位（不要再开第八个对等主区域）

| 槽 | 放什么 | 别放什么 |
|----|--------|----------|
| MENU_BAR | 工程、脚本、工作区、导出 | 每天都要点的那个主按钮 |
| TOOL_STRIP | 当前工作区的工具 | 三个工作区的工具一次性铺开 |
| LEFT_HIERARCHY | 已经在场景里的节点 | 网上那些还没下载的资产 |
| LEFT_LIBRARY | 本地和官方资产，往场景里加 | 已经在场景里的树 |
| CENTER_STAGE | 默认视口；审片时换成画布 | 长期并排两个中心 |
| RIGHT_INSPECTOR | 只编辑当前选中 | 全局偏好；整份剧本文本（长文走菜单「编辑剧本」） |
| BOTTOM_STRIP | Shot 一条条排开 | 再一个默认占满中间的思维导图画布 |
| STATUS_BAR | 工程名、是否未保存、一点提示 | 新功能入口 |

新功能先说进哪一格。官方商店是资源库的一种筛选，不是新的主窗口。

## 三个工作区

置景：主舞台是视口，主按钮是「添加到场景」，工具偏选择和变换。  
掌机：主舞台还是视口，主按钮是「关联到当前 Shot」，工具偏预设机位。  
审片：主舞台换成画布，主按钮是导出。

## 真要改界面时（还没做）

现有四个面板先搬家进槽，功能一个别加。  
再打通选择，检查器跟着走。  
每区只留一个主按钮。  
最后才换颜色图标。

跟 AI 说「只把分镜挪到底条，别动导出逻辑」，比说「专业一点」有用。

代码仍然按名词进 Script、Scene、Camera。IA 不管新建 CMake 库，只管面板出现在哪个槽。搬家如果需要新命令，还是走产品里那套 Command 再 visit。
