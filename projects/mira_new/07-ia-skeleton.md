对照：当前 Demo 乱，主要是 IA 没锁——剧本、资源、视口、分镜都像同等重要的窗口，没有「当前工作是什么」。模块接缝（Command、快照）已经有了，缺的是屏幕组织法。

## 六条哲学在本产品上的翻译

1. 一次一个主舞台 → 默认 **3D 视口**；分镜审片是另一个工作区，不是长期并排的第二主角。  
2. 一次一种选中 → 当前选择 ∈ {场景物体, 相机, Shot}，检查器只认这一个。  
3. 按职责分区 → 左层级/库，中视口，右检查器，下镜头条，上菜单与工具。  
4. 模式切换 → 置景 / 掌机 / 审片，chrome 不换。  
5. 名字稳定 → 下表英文槽名 + 中文职责，不随功能改名。  
6. 进阶藏起来 → 每工作区一个主 CTA；导出、官方下载等进菜单或折叠。

## 1. 主舞台

**默认：CENTER_STAGE = 3D 视口。**  
分镜画布降级为 BOTTOM_STRIP；进入「审片」工作区时，CENTER_STAGE 临时换成画布，视口退成可切回，不并排抢中间。

（若产品以后认定「导演台本质是审片」，只改这一行，并走建议卡批准。未批准前按视口为主。）

## 2. 选中

系统只有一种 `CurrentSelection`：

| 用户点击 | 选中类型 | 检查器编辑 |
|----------|----------|------------|
| 视口里的模型 / 层级条目 | 场景物体 | 变换、名称 |
| 相机列表 / 视口相机控件 | 相机 | 预设、轨道参数 |
| 底条卡片 / 剧本 Shot 行 | Shot | 关联相机、标题；可跳转视口 |

点分镜卡片 = 选中 Shot（可同时把视口切到关联相机，这是跳转，不是第二套选择）。  
禁止：剧本面板高亮一套、视口高亮另一套、互不更新检查器。

## 3. 七个槽 + 状态栏（不许第八个对等主区域）

| 槽 | 放什么 | 明确不放 |
|----|--------|----------|
| MENU_BAR | 工程、脚本、工作区、导出 | 日常主 CTA |
| TOOL_STRIP | 当前工作区工具：移动/机位预设/关联 | 三个工作区的工具同时铺开 |
| LEFT_HIERARCHY | 场景节点 | 未进口的网上资产浏览 |
| LEFT_LIBRARY | 本地+官方资产，往场景里加 | 已在场景中的节点树 |
| CENTER_STAGE | 默认视口；审片工作区为画布 | 长期左右两个中心 |
| RIGHT_INSPECTOR | 只编辑 CurrentSelection | 全局偏好、整份剧本文本编辑（长文可进菜单「编辑剧本」） |
| BOTTOM_STRIP | Shot 序列（现 Storyboard 的序列职责） | 再一个占满中间的思维导图画布当默认 |
| STATUS_BAR | 工程名、dirty、快捷提示 | 新功能入口 |

新功能必须声明进上表某一格。例如「官方商店」进 LEFT_LIBRARY 的一个筛选，不进新主窗口。

## 4. 工作区（3 个）

| 工作区 | 主舞台 | 主 CTA | TOOL_STRIP 侧重 |
|--------|--------|--------|-----------------|
| 置景 | 视口 | 添加到场景 | 选择/变换 |
| 掌机 | 视口 | 关联到当前 Shot | 预设机位、切相机 |
| 审片 | 分镜画布 | 导出 | 刷新缩略图、跳转镜头 |

## 5. 只在骨架里优化的顺序（仍未执行代码）

1. 现有 Script / Library / Viewport / Storyboard 四个面板 **搬家进槽**，功能零新增  
2. 统一选择，打通检查器  
3. 每工作区一个主按钮，合并重复入口  
4. 最后才换皮  

Vibe 下单示例：「只把 Storyboard 挪到 BOTTOM_STRIP，不要动导出逻辑。」

## 与产品 `07` 模块落点

代码仍按名词进 Script/Scene/Camera/…。IA 不授权新建 CMake 模块，只授权 **UI chrome 进哪个槽**。若搬家需要新 Command（例如 SetWorkspaceCommand），仍走 `07` 的 Command → visit，槽位只决定面板可见性。
