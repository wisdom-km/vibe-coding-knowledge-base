# 修过的坑

主路径能跑之后，才轮到「能给别人装、能给别人看懂」。下面这些都有 commit，不是事后编的。

视口滚轮会闪。缩略图为了拿一张小图去 reset 交换链，还在主循环里同步回读，多出来的一帧把刚清空的画面呈上去。视口窗口还把滚轮当成 ImGui 滚动条。后来回读改成异步，视口用看不见的按钮吃输入，尺寸抖两像素内不重建。导出仍走原来的同步回读。第二调用方不能破坏第一调用方的帧。

Windows 安装包编不出中文向导。winget 装的 Inno Setup 6 不带那份中文语言文件。向导改回默认英文，应用里仍是中文。包装工具链不等于产品的 i18n。

GitHub README 里的 Mermaid 不能缩放，后来做了网页，SVG 又被 `max-width` 挤扁。Pages 上单独看图，正文仍只在 `docs/dev-map`。目录页一度从 08 倒排到 00，又改回来。

中文路径是预防性的坑。目标用户就在中文环境。转换只放在 Platform，测试必须带非 ASCII 文件名。Shader 源码进仓库，二进制构建期生成，别提交。本机没有 Mac，CI 绿只是门禁，别假装已经在 Mac 上点过一遍。

`src/AI` 有 Mock，Application 里搜不到 AI。冻结它，不接线也不往里堆供应商。往里填才是空房间。

能编译不是验收。交换链呈上去之后画面还在，才是。
