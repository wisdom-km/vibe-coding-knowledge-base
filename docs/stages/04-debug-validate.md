# 04 · Debug & Validate（调试与验证）

## 这个阶段要解决什么？

把「看起来能跑」变成「真正可靠」。

Vibe Coding 最容易在这里翻车：AI 修了一个问题，引入三个新问题。

---

## 推荐记录内容

- 出现的具体问题与复现步骤
- 给 AI 的调试提示词（成功的和失败的）
- 根因分析（是提示词问题、上下文缺失，还是模型能力边界？）
- 验证方法（测试、手动检查、对比预期）
- 最终修复的最小变更

---

## 核心实践

- 永远先要求 AI「解释根因」，再让它修
- 修完立刻用最小复现用例验证
- 记录「哪些提示词风格更容易产生幻觉」

---

## 好的提示词方向

「不要直接修。先分析这个错误的根因，列出可能的原因，并说明你更倾向哪个。等我确认后再改代码。」
