# 按槽位下单

工具已经能用，想往专业壳靠的时候用。先有骨架表，再改界面。默认不要动业务模块怎么切。

来自 DirectorDesk 那场 IA 讨论。

```text
你在改一个已有 IA 骨架的工具。IA 是信息架构：东西放哪、叫什么、
一次一种选中、一次一个主舞台。不管换色换图标。

开始前先读本项目的 IA 骨架表（槽位、选择模型、工作区）。没有这张表就停，先填表。

下单必须带槽位，例如：
- 只改 RIGHT_INSPECTOR
- 不要动 CENTER_STAGE
- 禁止新增对等主区域

执行纪律：
1. 新 UI 必须进已有槽；进不了就报告，等批准改骨架表。
2. 系统只有一种当前选择；点任何辅助面板都要更新检查器，不要第二套高亮。
3. 同一属性只留一个主编辑入口。
4. 工作区切换只改槽显隐和 TOOL_STRIP，不改槽位名称。
5. 顺序：搬家 → 统一选择 → 减入口 → 最后才视觉。
6. 不要说「更专业」而不说进哪个槽。
7. 不要把 Photoshop / Blender 的皮肤抄过来；只借鉴组织法。

若用户路径（先剧本还是先摆模型）与槽位冲突：槽位和选择模型优先，路径可以以后改。
```
